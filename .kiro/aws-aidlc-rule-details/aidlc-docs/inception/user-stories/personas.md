# ペルソナ定義

---

## ペルソナ1: ゲスト購入者（初回・アカウントなし）

**名前**: 田中 あおい（仮名）  
**年齢**: 28歳  
**職業**: フリーランスデザイナー  
**利用デバイス**: スマートフォン（主）、PC（副）

### 背景・特徴
- SNSや検索で商品を見つけてサイトに訪れる
- アカウント登録の手間を嫌い、「すぐ買えなければ離脱する」タイプ
- デジタル商品（フォント、テンプレート、素材集など）を頻繁に購入する
- クレジットカードを持っており、オンライン決済に慣れている

### ゴール
- 目的の商品を素早く見つけ、最短ステップで購入を完了したい
- 購入後すぐにダウンロードして使い始めたい

### 課題・ペインポイント
- 「カート → 登録 → ログイン → 住所入力 → 決済」という長い購入フローを嫌う
- 購入後に商品が届かない・ダウンロードできないトラブルを経験したことがある
- スマートフォンで操作しにくいUIにストレスを感じる

### このシステムとの関わり
- 商品一覧を閲覧する
- 商品詳細を確認する
- ゲストとして2ステップで購入する
- メールでダウンロードリンクを受け取る
- 購入後にアカウント登録を任意で選択する

## ペルソナ2: 会員ユーザー（リピーター・アカウントあり）

**名前**: 佐藤 けんじ（仮名）  
**年齢**: 35歳  
**職業**: Web制作会社勤務（ディレクター）  
**利用デバイス**: PC（主）、スマートフォン（副）

### 背景・特徴
- 過去に一度ゲスト購入した後、アカウントを作成したリピーター
- 素材・テンプレート類をまとめて購入することが多い
- 「以前買ったあの素材をまた使いたい」というシーンが頻繁にある

### ゴール
- 購入履歴から過去に買ったコンテンツを素早く再ダウンロードしたい
- 新着商品をチェックして定期的に購入したい

### 課題・ペインポイント
- ダウンロードURLの有効期限が切れたときに再取得できない
- 過去の購入一覧が見当たらず、いつ何を買ったか分からなくなる

### このシステムとの関わり
- ログインして購入する
- マイページで購入履歴を確認する
- 購入済みコンテンツを再ダウンロードする
- パスワードを忘れた場合にリセットする

## ペルソナ3: サイト管理者（オーナー・バックオフィス担当）

**名前**: 山田 みか（仮名）  
**年齢**: 42歳  
**職業**: ECサイトオーナー（個人事業主）  
**利用デバイス**: PC（主）

### 背景・特徴
- デジタルコンテンツ（イラスト素材・Webテンプレート等）を制作・販売している
- 技術的な知識は限定的だが、管理画面の基本操作は習得済み
- 月に数十件〜数百件の注文を処理する

### ゴール
- 商品の登録・更新を手軽に行いたい
- 注文状況を一目で把握し、問題があればすぐ対応したい
- 誰がどの商品を購入したか（不正対応のために）確認できるようにしたい

### 課題・ペインポイント
- 管理画面が複雑で、必要な情報にたどり着くのに時間がかかる
- デジタル商品の不正ダウンロード・チャージバックが心配
- 商品を非公開にしたり価格変更したりする作業に時間がかかる

### このシステムとの関わり
- 管理画面にログインする
- 商品を登録・編集・公開/非公開にする
- 注文一覧を確認し、詳細を参照する
- 顧客（購入者メール・氏名）の一覧を確認する
