
## 開発シーケンス

| フェーズ | ユニット | 依存 | 備考 |
|---|---|---|---|
| 1（必須・先行） | U-01 | なし | DB・API・サービス層が揃わないと他が動かない |
| 2（並行可能） | U-02 + U-03 | U-01完了 | 独立して開発・テスト可能 |
