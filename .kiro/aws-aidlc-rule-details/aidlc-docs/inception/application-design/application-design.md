# アプリケーション設計（統合ドキュメント）

## 設計サマリー

デジタル商品ECサイトを **Next.js モノリポ** として構築します。フロントエンド（購入者向け・管理者向け）とバックエンドAPI（API Routes）を単一プロジェクトにまとめ、Vercelにデプロイします。外部サービス（Stripe・AWS・SES）との連携はサービス層で抽象化します。

## 設計上の重要な決定事項

| 決定事項 | 内容 | 理由 |
|---|---|---|
| モノリポ構成 | フロントエンド・バックエンドを単一Next.jsプロジェクトに統合 | 小規模・シンプルさ重視。管理コスト最小化 |
| Stripe Elements使用 | カード情報はStripeのiframe内でのみ処理 | PCI DSS準拠・カード情報をサーバーに触れさせない |
| Webhook必須 | 決済完了はWebhookで非同期受信 | フロントエンドからの完了通知はなりすまし可能なため |
| 署名付きURL | CloudFrontの署名付きURLでダウンロード保護 | S3を直接公開しない・有効期限・回数制限を実装 |
| NextAuth.js | 認証は既製ライブラリに任せる | 独自実装より安全・セッション管理が容易 |
| DB: PostgreSQL | リレーショナルDB（注文・商品・ユーザーの関係を表現） | 構造化データに適切・Supabaseで手軽に利用可能 |
