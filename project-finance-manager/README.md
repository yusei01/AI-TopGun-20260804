# 案件収支管理アプリ

案件単位で売上・支払いを管理する社内向けWebアプリです。

## 起動手順

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. データベースの初期化

```bash
npx prisma migrate dev --name init
```

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

---

## 初回セットアップ（起動後の設定）

アプリを起動したら、まず **マスタ管理** から以下の順番で登録してください。

### ① 年度設定（必須）
支払い計算に使用する係数を登録します。

- **間接費係数**：プロパーの原価に対する間接費の割合（例：0.15 = 15%）
- **基準販売費係数**：（原価＋間接費）に対する基準販売費の割合（例：0.10 = 10%）

### ② 担当者登録
- プロパーの場合は時間単価も登録しておくと支払い登録時に自動入力されます

### ③ 協力会社登録
- 月額基準金額を登録しておくと支払い登録時に自動入力されます

### ④ クライアント登録
- 案件登録時にプルダウンで選択できます

## 主な機能

| 画面 | 機能 |
|------|------|
| 案件一覧 | 案件の一覧表示・フィルタリング |
| 案件詳細 | 売上・支払い明細・粗利の確認 |
| 売上登録 | 案件種別に応じた売上の登録（自動計算） |
| 支払い登録 | プロパー・協力会社の支払い登録（自動計算） |
| 集計・レポート | 月次・上期・下期・通期の集計 |
| マスタ管理 | 年度設定・担当者・協力会社・クライアントの管理 |

## 計算ロジック

### 売上

**準委任契約**
- 下限時間未達でも減額なし
- 上限時間超過分のみ加算（単価 = 基準金額 ÷ 計算基準時間）

**SES**
- 下限時間未達：控除（単価 = 基準金額 ÷ 計算基準時間）
- 上限時間超過：加算

**一括請負**
- 請求明細の合計が売上合計

### 支払い

**プロパー**
```
原価       = 稼働時間 × 時間単価
間接費     = 原価 × 間接費係数
基準販売費 = (原価 + 間接費) × 基準販売費係数
支払い合計 = 原価 + 間接費 + 基準販売費
```

**協力会社**
```
稼働 < 140h   → 支払い = 基準金額 - (140 - 稼働h) × (基準金額 ÷ 140)
稼働 140〜180h → 支払い = 基準金額
稼働 > 180h   → 支払い = 基準金額 + (稼働h - 180) × (基準金額 ÷ 180)
基準販売費 = 基準金額 × 基準販売費係数
支払い合計 = 上記 + 基準販売費
```
